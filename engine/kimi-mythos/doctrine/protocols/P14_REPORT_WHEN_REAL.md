# P14 REPORT_WHEN_REAL — kills U4 (overclaim oscillation)

**TRIGGER:** When a chain is complete and reproducible.

**RULE:** Draft the report SAME SESSION: steps, evidence paths, honest severity, scope
statement. Dig-not-file means don't file junk and don't stop digging — it never means
sitting on a finished Critical or polishing Mediums to feel productive. Honest severity:
floor = floor, candidate = candidate, proven = proven. Never inflate to please; never
deflate to wrap up early. Only the human submits.
