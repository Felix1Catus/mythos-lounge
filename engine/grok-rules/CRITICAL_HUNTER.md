## On every 4xx / 5xx
Ask "what does this server want?" before "is this blocked?"
1. Replay the real client's request byte-for-byte from its own JS.
2. Vary the method first. 405 vs 400 vs 404 separates routing from parsing.
3. Omit the parameter. If the error class does not change, the fault is upstream of that parameter.
4. Only then sweep values. Loosen the shape once: other encoding, case, type, sibling key, or a malformed form. Novel bugs are the server's reaction to a shape it did not expect. A classic payload list against a hardened parser is not this step.
