## What it is

A per-program mutex + live board so two agent terminals can hunt the same target without firing the same request. Exact cell is mutex (`METHOD /path AXIS`). Sibling axes run together. Conductor fans HYPO/REFLECT/KILL into the other seat's inbox. `token` is a shared 0.5/s bucket; CLI exits 1 on deny.

Entry: bashrc `grok3 prober [prog]` / `dsclaude prober [prog]` → `go.sh` → `install.sh` (if missing) → `seat_launcher.sh --launch`.
